# Епта Семкоед

HTML5-игра для Telegram Mini App. Весь проект — один файл `index.html` и иконка `icon.png`. Графика рисуется кодом, музыка генерируется кодом, ничего подгружать не надо.

## 1. Залить на GitHub Pages

1. Зарегистрируйся на github.com и нажми **New repository**. Назови его, например, `epta-semkoed`, выбери **Public** и нажми **Create repository**.
2. На странице репозитория нажми **uploading an existing file**, перетащи туда `index.html` и `icon.png`, потом **Commit changes**.
3. Открой **Settings → Pages**. В **Source** выбери **Deploy from a branch**, в **Branch** — `main` и `/ (root)`, нажми **Save**.
4. Через 1–2 минуты игра откроется по адресу:
   `https://ТВОЙ_НИК.github.io/epta-semkoed/`
   Проверь ссылку в обычном браузере.

## 2. Подключить к Telegram

1. Напиши в Telegram боту **@BotFather** → `/newbot` → придумай имя и юзернейм бота (должен заканчиваться на `bot`).
2. Там же: `/mybots` → выбери бота → **Bot Settings → Menu Button → Configure menu button** → вставь ссылку на GitHub Pages и подпиши кнопку, например «Че, ебашим?».
3. Готово: открываешь своего бота, жмёшь кнопку внизу — игра запускается внутри Telegram.

Если хочешь, чтобы игра открывалась ссылкой вида `t.me/твой_бот/game`: в @BotFather сделай `/newapp`, выбери бота, загрузи картинку 640×360, укажи ту же ссылку и короткое имя `game`.

## Обновление

Чтобы залить новую версию, загрузи в репозиторий новый `index.html` поверх старого. GitHub Pages обновится за минуту.

## Что внутри

- 30 уровней в 6 локациях: «У подъезда», «Гаражи», «Остановка», «Рынок», «Стройка», «Электричка».
- Режим «До упора» — бесконечный, с рекордом.
- 8 пацанов, у каждого своя фишка; покупаются за заработанные бабки.
- Сохранение в браузере и в облаке Telegram (CloudStorage).
- Вибрация через Telegram при тапах, кнопка «Назад» в шапке Telegram.
